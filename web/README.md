# Дневник эмоций

Локальный прототип дневника эмоций и цитат.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который появится в терминале (обычно `http://localhost:3000`).

## Документы

- `PRD.md` — сценарий, функции, ограничения и проверки;
- `DESIGN.md` — правила визуального стиля;
- `COMMENTS.md` — комментарии к работе;
- `../референс цветовой.png` и `../референс идеи.png` — исходные изображения.

## Хранение

Записи сохраняются только в `localStorage` браузера. Для сброса демо удалите данные сайта в настройках браузера.
