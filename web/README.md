# Дневник эмоций

Локальный прототип дневника эмоций и цитат.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который появится в терминале (обычно `http://localhost:3000`).

Чтобы открыть приложение с телефона в той же Wi-Fi-сети:

```bash
npm run dev -- --hostname 0.0.0.0 --port 3000
```

При первом открытии введите имя. Это mock-авторизация без пароля, сервера и внешних сервисов. Локальный профиль и его сессия восстанавливаются после перезагрузки страницы; кнопка выхода находится в верхней панели.

В разделе «Цитаты» кнопка «Другая мысль» загружает случайную цитату и автора из `https://dummyjson.com/quotes/random`. API не требует ключа. Если сеть недоступна, приложение автоматически показывает цитату из локальной подборки.

## Документы

- `PRD.md` — сценарий, функции, ограничения и проверки;
- `DESIGN.md` — правила визуального стиля;
- `ARCHITECTURE.md` — структура данных и правила локального хранения;
- `REFLECTION.md` — краткая рефлексия о работе с ИИ;
- `COMMENTS.md` — комментарии к работе;
- `../референс идеи.png` и `../референс цветовой.png` — исходные визуальные референсы, которые нужно включить в итоговый архив вместе с папкой `web`.

## Хранение

Данные сохраняются только в `localStorage` браузера:

- `tiho:users` — локальные профили;
- `tiho:session` — активная сессия;
- `tiho:emotions` — эмоциональные записи с `userId`;
- `tiho:emotion-drafts` — черновики комментариев к состоянию;
- `tiho:quotes` — цитаты, авторы, источники и комментарии с `userId`.

Данные разных локальных профилей не смешиваются, но mock-вход не защищает их паролем. Данные не синхронизируются и удалятся при очистке хранилища сайта.
