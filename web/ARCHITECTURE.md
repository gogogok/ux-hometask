# Архитектура данных «Дневника эмоций»

## Общая схема

Приложение работает полностью в браузере. React хранит текущее состояние интерфейса в памяти, а данные между запусками сохраняются в `localStorage`. Сервер, внешняя база данных и настоящая регистрация не используются.

## Ключи localStorage

### `tiho:users`

Массив локальных профилей:

```json
[
  {
    "id": "user-1795000000000-a1b2c3",
    "name": "Даша",
    "createdAt": "2026-11-18T10:00:00.000Z"
  }
]
```

Имя сравнивается без учёта регистра. При повторном входе с тем же именем используется прежний `id`.

### `tiho:session`

Текущий локальный профиль:

```json
{ "userId": "user-1795000000000-a1b2c3" }
```

Ключ удаляется при выходе. Профиль и его записи при этом сохраняются.

### `tiho:screen`

Строка `emotions`, `quotes` или `calendar` с последним открытым разделом. Значение обновляется при навигации и восстанавливается после перезагрузки для активной сессии.

### `tiho:emotions`

Массив эмоциональных записей:

```json
[
  {
    "id": 1795000100000,
    "userId": "user-1795000000000-a1b2c3",
    "createdAt": "2026-11-18T10:01:40.000Z",
    "note": "Спокойное утро",
    "values": {
      "joy": 72,
      "calm": 48,
      "excitement": 34,
      "sadness": 18,
      "anxiety": 22,
      "irritation": 8
    }
  }
]
```

### `tiho:emotion-drafts`

Черновик комментария к состоянию хранится отдельно от календарной записи и отдельно для каждого профиля:

```json
{
  "user-1795000000000-a1b2c3": {
    "dayKey": "2026-11-19",
    "note": "Несохранённая мысль"
  }
}
```

Черновик обновляется при вводе текста и восстанавливается после перезагрузки только в тот же календарный день. Он не создаёт запись в календаре — для этого пользователь должен нажать кнопку сохранения колбы.

### `tiho:quotes`

Массив сохранённых цитат и комментариев:

```json
[
  {
    "id": 1795000200000,
    "userId": "user-1795000000000-a1b2c3",
    "createdAt": "2026-11-18T10:03:20.000Z",
    "quote": "True success is reaching our potential without compromising our values.",
    "author": "Muhammad Ali",
    "source": "dummyjson",
    "reflection": "Мне важно помнить об этом сегодня."
  }
]
```

## Правила данных

- В один календарный день у одного пользователя хранится одна эмоциональная запись и одна цитата.
- Повторное сохранение обновляет запись этого дня, не затрагивая других пользователей.
- Несохранённый комментарий к состоянию остаётся отдельным черновиком и не показывается в календаре.
- Для каждого пользователя хранится не более 370 эмоциональных и 370 цитатных записей.
- Цитату можно сохранить с пустым `reflection`; комментарий сохраняется только после сохранения выбранной цитаты.
- Поля `author` и `source` необязательны для совместимости со старыми локальными записями.
- Старые записи без `userId` при первом входе закрепляются за первым локальным профилем.
- Календарь строится только из записей активного пользователя.

## Ограничения и безопасность

Mock-авторизация нужна для демонстрации сценария и разделения локальных записей, но не защищает данные: пароля и проверки личности нет. Данные доступны только в текущем браузере, не синхронизируются между устройствами и удаляются при очистке данных сайта.

## Внешние данные

При первом открытии раздела и каждом нажатии кнопки обновления выполняется `GET https://dummyjson.com/quotes/random`. Ответ ожидается в виде объекта с полями `quote` и `author`; ключ доступа не нужен. Полученная цитата сохраняется в `tiho:quotes` только после действия пользователя. При ошибке HTTP, сети или неполном ответе сохраняется последняя загруженная цитата либо показывается состояние ошибки с повторным запросом.
