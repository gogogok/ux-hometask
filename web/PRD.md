# PRD: дневник эмоций и цитат

## Статус

- Версия: MVP 1.2
- Дата: 18 ноября 2026
- Состояние: основной сценарий и локальная mock-авторизация реализованы

## Идея и пользователи

Это небольшой личный веб-дневник для человека, которому хочется замечать своё эмоциональное состояние без сложных анкет и оценок. Приложение помогает назвать несколько одновременных чувств, увидеть их как единый визуальный «состав» и сохранить короткий контекст. Второй раздел предлагает бережную мотивирующую мысль и место для личной реакции.

## Задача

Снизить порог регулярной рефлексии: вместо длинной записи пользователь за 1–2 минуты отмечает интенсивность чувств, видит понятный образ и при желании добавляет одну заметку.

## Основной сценарий MVP

1. Пользователь вводит имя на локальном mock-экране входа.
2. Открывает раздел «Эмоции» и настраивает интенсивность шести эмоций ползунками.
3. Видит, как цветные слои в сосуде меняются в реальном времени, и какое чувство сейчас самое сильное.
4. При желании пишет короткий контекст и сохраняет состояние.
5. Переходит в раздел «Цитаты», запрашивает новую мысль из внешнего API и отдельно сохраняет её; при желании добавляет комментарий отдельным действием.
6. Открывает календарь, выбирает день и видит сохранённые колбу, цитату и комментарии.
7. Может выйти и войти под другим локальным именем; записи разных профилей не смешиваются.

## Экраны и переходы

### 0. Вход

- локальная форма входа по имени без пароля;
- короткое состояние загрузки с индикатором имитирует процесс авторизации;
- после входа сессия восстанавливается при перезагрузке страницы;

### 1. Эмоции

- дата;
- шесть ползунков интенсивности;
- необязательное текстовое поле, черновик которого сохраняется после перезагрузки;
- сосуд с цветными слоями;
- подсказка о доминирующей эмоции;
- кнопка сохранения и дата последней записи.

### 2. Цитаты

- мотивирующая мысль;
- кнопка «Другая мысль», загружающая новую цитату из внешнего API;
- кнопка сохранения непосредственно на карточке цитаты;
- отдельное поле и отдельная кнопка сохранения личного комментария;
- превью сегодняшней записи; календарь открывается через верхнюю навигацию.

### 3. Календарь

- месячная сетка с мини-колбой для каждого дня;
- отметка о сохранённой цитате;
- переключение месяцев;
- карточка выбранного дня с большой колбой, цитатой, комментарием к состоянию и комментарием к цитате.

Переход между экранами выполняется верхней навигацией без перезагрузки страницы.

## Функции первой версии

1. Выбор интенсивности нескольких эмоций.
2. Динамическая визуализация эмоционального состава в сосуде.
3. Сохранение эмоциональной записи с необязательной заметкой.
4. Загрузка случайных мотивирующих цитат и авторов из DummyJSON API с локальным резервом при ошибке сети.
5. Независимое сохранение цитаты и комментария к ней.
6. Просмотр сохранённых дневных записей в календаре.

## Данные

Данные хранятся в `localStorage` текущего браузера:

- `tiho:users` — локальные профили с идентификатором, именем и датой создания;
- `tiho:session` — идентификатор текущего профиля;
- `tiho:emotions` — до 370 дневных эмоциональных записей на профиль;
- `tiho:emotion-drafts` — несохранённый комментарий текущего дня для каждого профиля;
- `tiho:quotes` — до 370 дневных записей цитат на профиль.

Каждая запись содержит `userId`. Сохранённая API-цитата дополнительно содержит автора и источник. В один календарный день для одного профиля хранится одна колба и одна цитата: повторное сохранение обновляет запись этого дня. Старые записи без `userId` при первом входе закрепляются за первым локальным профилем, поэтому прежние данные не теряются.

Mock-авторизация имитирует выбор локального пользователя, но не является защитой данных: в ней нет пароля, сервера и проверки личности. Данные не синхронизируются между устройствами, не восстанавливаются после очистки данных браузера и доступны только в том браузере, где были созданы.

## Технические решения

- React 19 + TypeScript;
- Vinext/Vite для локальной разработки и сборки;
- Radix UI Slider как доступный компонент ползунка;
- Lucide React для иконок;
- CSS без отдельной визуальной UI-библиотеки;
- DummyJSON Quotes API (`https://dummyjson.com/quotes/random`) без ключа и регистрации;
- адаптивная компоновка для компьютера и телефона.

## Не входит в первую версию

- настоящая регистрация и синхронизация;
- пароль, серверная сессия и внешняя база данных;
- графики динамики и статистика по периодам;
- редактирование и удаление прошлых записей;
- уведомления;
- рекомендации по психическому здоровью;
- публикация и общий доступ.

При отсутствии сети или ошибке API приложение показывает следующую цитату из встроенной локальной подборки. Основной сценарий и сохранённые записи от внешнего сервиса не зависят.

## Проверки результата

1. Войти по имени и обновить страницу: тот же локальный профиль должен восстановиться.
2. Изменить два ползунка: высота и пропорции цветных слоёв в сосуде должны измениться, а сильнейшая эмоция — обновиться.
3. Сохранить эмоциональную запись с комментарием и обновить страницу: значения колбы и комментарий должны восстановиться.
4. Изменить комментарий к состоянию, не сохраняя колбу, и обновить страницу: черновик должен остаться в поле, но не появиться в календаре.
5. Перейти в «Цитаты», загрузить новую цитату из API, сохранить её кнопкой на карточке, затем отдельно добавить комментарий: в календаре должны отображаться цитата и сохранённый комментарий; цитата также должна сохраняться без комментария.
6. Отключить сеть или заблокировать API: вместо ошибки интерфейс должен показать локальную цитату и сохранить работоспособность раздела.
7. Выйти, войти под другим именем и убедиться, что записи первого профиля не видны; затем снова войти первым профилем и проверить восстановление его данных.
